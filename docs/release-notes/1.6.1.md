This release renames the program from supergbamidi to agbsf2. The conversions match 1.6.0's. Only the program's name in the files differs. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.6.0

- The program is now called agbsf2. The Windows executable is `agbsf2.exe`. The release's zip is `agbsf2-1.6.1-win-x64.zip`. On macOS the build makes `Agbsf2.app`. The CMake option that builds the tests is now `AGBSF2_BUILD_TESTS`.
- Each SoundFont names agbsf2 in its software and comment fields. Each MIDI file names agbsf2 in a text event. 1.6.0's files named supergbamidi there. Nothing else in the files changes.
- The messages name agbsf2. Four of them are reworded. When agbsf2 finds no driver, the message ends with "this game's music uses another engine, or a driver version that agbsf2 doesn't support". For an unsupported build of Krawall, the message begins "found Krawall, but not a build that agbsf2 supports". For Konami's driver, two messages now read "agbsf2 can't read these samples and skips their notes" and "this game has an older revision of Konami's driver with commands that agbsf2 can't read".

## Known limitations

The limitations listed for 1.6.0 still apply. See "Accuracy" and "Known issues" in the README for the details.
