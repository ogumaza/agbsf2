In this release, the sample notes of Nintendo R&D1's driver no longer release too fast. This affects *WarioWare, Inc.: Mega Microgame$!* and *Rhythm Tengoku*. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D1's, Nintendo R&D2's, AlphaDream's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.9.0

### Nintendo R&D1's driver

- A release in the driver falls in a straight line in level. A SoundFont release falls in a straight line in decibels. To keep the loudness close, the conversion stretched each release 3 times up to 5 frames, rising to 6 times from 16 frames on. Most sample notes of the driver release in under 16 frames. Their zones therefore released too fast. A sample zone now releases over 7 times the frames of the driver release, whatever their number. PSG zones release as before.

## Known limitations

The limitations listed for 1.9.0 still apply. See "Accuracy" and "Known issues" in the README for the details.
