In this release, the beat of Ubisoft Milan's songs counts the wave notes that play at 75 % volume. This affects *The Mummy*. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D1's, Nintendo R&D2's, AlphaDream's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.9.1

### Ubisoft Milan's driver

- Bit 7 of NR32 plays the wave channel at 75 % volume. The conversion read only bits 5 and 6, so it took a wave note with bit 7 set and the other two clear as silent when it worked out a song's beat. Those notes now count. In *The Mummy*, six songs get new tempos, and their notes move onto the new beat.

### MP2K

- In *Metroid Fusion*, a note command has two argument bytes: a key and a velocity. The `--dump` listings read a third byte below `0x80` as the note's extra length. The game plays that byte as the key of the next note, and the listings now show it that way. The MIDI files and SoundFonts don't change.

### Code from ntdlib

- Krawall and the drivers of Rare, Quintet, Nintendo R&D2, Brownie Brown and Ubisoft Milan now come from ntdlib, as MP2K and Konami's driver already did. Apart from the change to Ubisoft Milan's driver, the conversions are the same as in 1.9.1.
