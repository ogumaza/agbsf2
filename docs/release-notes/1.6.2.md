This release gives pitch bends their full range in every SoundFont. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.6.1

- Pitch bends reach their full range in every SoundFont. SoundFont 2.04's default modulator gives the pitch wheel only 127/128 of the range that RPN 0 sets. FluidSynth follows that default. Each semitone of a bend fell 0.78 cents short. A bend of 24 semitones fell 19 cents short. Every instrument now has a global zone whose modulators give the wheel the full range. The MIDI files don't change.
- The README's section on Krawall says how to make FluidSynth sound closer to a game that plays its samples point by point.

## Known limitations

The limitations listed for 1.6.0 still apply. See "Accuracy" and "Known issues" in the README for the details.
