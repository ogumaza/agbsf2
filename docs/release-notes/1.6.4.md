This release adds `--psg-exclusive`, an exclusive class for each PSG channel in MP2K's SoundFonts. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.6.3

- `--psg-exclusive` (MP2K only) gives each zone of a PSG voice with a slow release the exclusive class of the voice's channel. A track's next note on a PSG channel then ends the slow release of the note before it. The game cuts that note off there too. The option changes only the SoundFont, and it's off unless you ask for it. It works with `--single-sf2` and `--voice-channels`. The README's "SoundFont from MP2K" describes it.
- The SoundFont specification limits an exclusive class to the notes of one preset. FluidSynth applies a class to every note on the MIDI channel. The driver cuts such a note off too. A player that follows the specification lets a note of another voice fade out. The README says so.
- The README describes how FluidSynth handles the All Sound Off that `--voice-channels` writes where the channel's next note starts on the same tick with the same key.
