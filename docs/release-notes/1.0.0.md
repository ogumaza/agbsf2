First release of konamidi, a MIDI and SoundFont converter for Game Boy Advance games that use
Konami's sound driver. It finds the driver in a ROM or GSF rip and plays each song through a
model of that driver. Each song gets a Standard MIDI File and a SoundFont built from the game's
samples and Game Boy PSG waveforms.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.gba`,
`.gsflib` or `.minigsf` files on `konamidi.exe`, or run it in a terminal; `konamidi --help` lists
the options. The output of each file is written to a folder next to it.

For macOS and Linux, follow the build instructions in the README. On macOS the build also makes
`Konamidi.app`. You can drop files on it in the Finder.

## Features

- **Games.** Five revisions of Konami's driver, from *Yu-Gi-Oh! Dungeon Dice Monsters* to *Yu-Gi-Oh!
  Ultimate Masters Edition: World Championship Tournament 2006*. Detection identifies the driver by
  its code. Other games that use these revisions should therefore work too.
- **MIDI.** One tick per frame: every event lands on the frame the game plays it. Volume, pan, pitch
  bend, vibrato and echo sends become MIDI controllers, and loops are marked with `loopStart` and
  `loopEnd`.
- **SoundFont.** The SoundFont of each song contains the instruments it uses: the game's samples at
  their rates and loop points, the waveforms of the square and wave channels, and noise from the
  Game Boy's LFSR.
- **Detection.** `--info` lists the detected tables and any assumptions made during detection.
  Override options let you supply table addresses manually.

## Known limitations

- The Game Boy's PSG notes are written at equal-tempered pitch, although the hardware plays high
  notes slightly out of tune.
- The driver's echo is a feedback delay. The reverb send approximates it.
- A SoundFont player resamples more cleanly than the GBA's mixer.
- Unsupported commands stop the affected track and produce a warning.
- See "Accuracy" in the README for the details.
