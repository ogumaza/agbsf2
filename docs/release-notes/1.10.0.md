In this release, agbsf2 converts the music of 29 games with Logik State's sound driver, among them *Aero the Acro-Bat: Rascal Rival Revenge*. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D1's, Nintendo R&D2's, AlphaDream's, Brownie Brown's, Ubisoft Milan's and Logik State's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.9.4

### Logik State's driver

- agbsf2 now finds Logik State's driver and converts its modules to MIDI and SoundFont. The driver plays modules in the manner of ProTracker. Its modules come in three formats: `GBAMOD2.`, `GBAMOD1.` and `GBAMOD30`.
- *Aero the Acro-Bat: Rascal Rival Revenge* and *Zapper: One Wicked Cricket!* have `GBAMOD2.` modules. Each module becomes a song.
- *Pinball Challenge Deluxe* has `GBAMOD1.` modules. Each module holds many short pieces, and each piece becomes a song: the title's music, the music of the eight tables and their jingles.
- 26 later games have `GBAMOD30` modules, with eight builds of the driver between them. The README lists them. Their songs are numbered in the order of the game's table of songs. agbsf2 holds the driver's settings for these games alone. Another game with `GBAMOD30` modules gets an error.
- Each song plays at the music volume that the game sets when it starts. `--info` gives that volume. The new option `--music-volume N` converts at another volume, from 1 to 64. It implies `--driver logikstate`.
- `--driver logikstate` uses only this driver.
- The games' sound effects are single samples that their code starts. They aren't converted.
- The README's "Accuracy" section lists where a conversion differs from the game, under "Logik State's driver".

### Libraries

- agbsf2 now builds on ntdlib 3.7.0. It still builds on seqlib 1.4.0 and xsflib 1.10.0.

## Known limitations

The limitations listed for 1.9.0 still apply. See "Accuracy" and "Known issues" in the README for the details.
