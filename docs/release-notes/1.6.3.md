This release starts each file that mutes keys with the key pressures it needs. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.6.2

- Rare's driver mutes keys with key pressure, through a modulator in the SoundFont. A file whose SoundFont has that modulator now starts with a key pressure of 0 for each key that it plays before the tune gives the key a pressure. A player that keeps key pressures from one file to the next would otherwise mute the keys that the file before left muted. With `--single-sf2`, the shared SoundFont has the modulator once any tune of the set mutes keys. Every file of the set then starts with those key pressures.
- The README explains a difference in FluidSynth's level. FluidSynth plays every note 1.5 dB louder than the SoundFont specifies. Multiplying FluidSynth's gain by 0.84 gives the specified level.
- The notes on Brownie Brown's, Krawall's and Quintet's drivers correct the descriptions of a few commands.
- agbsf2 now builds on seqlib 1.2.0 and xsflib 1.3.0.
