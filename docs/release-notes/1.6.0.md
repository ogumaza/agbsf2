This release adds support for *Super Mario Advance 3: Yoshi's Island*. Its music plays on a revision of Nintendo R&D2's driver close to *A Link to the Past*'s. MIDI files from Rare's driver now mute the notes that the driver's mixer leaves out. MIDI files from Ubisoft Milan's driver now play the kit on MIDI channel 11 rather than on the drum channel. supergbamidi converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

It runs on 64-bit Windows 10 or later and doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `supergbamidi.exe`, or run it in a terminal. `supergbamidi --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Supergbamidi.app`. You can drop files on it in the Finder.

## Changes since 1.5.0

- *Super Mario Advance 3: Yoshi's Island* is supported. Its driver is *A Link to the Past*'s revision with quieter samples. When the game starts a piece of music, it can give the driver fewer sample voices or lower the music's volume. The conversion reads those settings from the game's code and plays each sequence with them.
- Rare's driver mixes at most 8 voices at a time. MIDI files from it now use polyphonic key pressure to mute the notes that the mixer leaves out. The SoundFont turns that pressure into silence. A player that ignores key pressure or the SoundFont's modulators still plays every note. In *Donkey Kong Country 3*, the mixer also leaves out the notes of a channel at volume 0.
- MIDI files from Ubisoft Milan's driver now play the kit on MIDI channel 11, and the SoundFont puts the kit's presets in bank 9. Players treat notes on channel 10 as drums. Some of them ignore a drum's note-off or the loop in its sample. In those players, a note that holds a looping sample stopped too soon or never stopped.
- supergbamidi now reads the tags of a GSF file with xsflib. Where a file has more than one `_lib` line, lines in a row join into one value, and a later line replaces an earlier one. The first line used to win. Only hand-made files have more than one `_lib` line.
- On macOS, `Supergbamidi.app` now gives its version in the Finder's Get Info window.
- Building from source now requires Git. The MIDI and SoundFont code comes from seqlib, and the PSF container reader, the file and console code and the parsing of numbers come from xsflib. The repository holds both as Git submodules. Clone it with `git clone --recursive`. In a clone made without `--recursive`, run `git submodule update --init` first.
- The Windows executable is now built with clang-cl. The supported platforms are macOS on Apple Silicon and Windows x64 built with clang-cl. Linux, Intel Macs, MSVC, MinGW and 32-bit Windows are no longer supported.

## Known limitations

Apart from Rare's voice limit, the limitations listed for 1.5.0 still apply. See "Accuracy" and "Known issues" in the README for the details.
