In this release, agbsf2 reads ten more builds of Krawall, from build 1.2.2.10 of its `player.c`, dated 2002/08/24, to the build dated 2005-04-21 and a changed form of it. Eleven more games convert, among them *007: Everything or Nothing*, *The Sims: Bustin' Out* and *Eragon*. A Krawall module can now have up to 32 channels. agbsf2 converts Game Boy Advance music to MIDI and SoundFont. It supports Konami's, Rare's, Quintet's, Nintendo R&D2's, Brownie Brown's and Ubisoft Milan's drivers, MP2K and Krawall.

The program runs on 64-bit Windows 10 or later. It doesn't require any runtime DLLs. Drop one or more `.gba`, `.gsflib` or `.minigsf` files on `agbsf2.exe`. You can also run it in a terminal. `agbsf2 --help` lists the options. Each file's output goes in a folder next to it.

On a Mac with Apple Silicon, follow the build instructions in the README. On macOS the build also makes `Agbsf2.app`. You can drop files on it in the Finder.

## Changes since 1.7.1

### Krawall

agbsf2 now reads these builds of Krawall. The games listed with each build convert.

| Build | Games |
|---|---|
| `player.c` 1.2.2.14, dated 2002/09/12 | *Racing Fever* |
| `player.c` 1.4, dated 2003/03/19 | *007: Everything or Nothing* |
| the build dated 2003/09/01 | *Digimon Racing*, as before, and *The Sims: Bustin' Out*. *The Sims: Bustin' Out* plays its music with interpolation. |
| the build dated 2004/09/17 | *Juka and the Monophonic Menace* |
| the build dated 2004/11/14 | *Babar to the Rescue* |
| the build dated 2005-04-21 | *Eragon* |
| a build with no version string | *Puppy Luv: Spa and Resort* |
| a changed form of the build dated 2005-04-21 | *Big Mutha Truckers*, *Street Racing Syndicate*, *M&M's Break 'Em* and *Princess Natasha* |

- agbsf2 also reads builds 1.2.2.10, 1.2.2.15 and 1.2.2.17 of `player.c`. Homebrew games and a prototype use them. A game with another build of Krawall that has a version string gets an error that gives the string.
- A module can have up to 32 channels. `--tracks` takes a Krawall module's channels 0 to 31. In a module with more than 15 channels, channels share MIDI channels. The 15 channels whose notes last longest take a MIDI channel each. Each other channel shares the MIDI channel whose notes it overlaps least. On a shared MIDI channel, each note sets its program, pan, expression and bend again. Where notes of two channels on one MIDI channel sound at once, the converter warns and gives the time they overlap.
- A game can play its music through a table of what it plays. Each entry gives a module, the mode for `krapPlay()` and a song. Detection reads such a table through the game's routine that plays its entries, in the form that *Eragon* has. Each entry becomes a song, in the table's order, before the modules that no entry plays. An entry that repeats an earlier one is left out. The song plays the module in the entry's mode, from the entry's song where the module has markers. In a mode without the loop, the song stops at the module's end, or in song mode at the next `+++`. The MIDI file then has no loop markers. A module that jumps back to an earlier order still loops, in any mode. `--info` lists the table and the songs whose mode doesn't loop.
- The changed build keeps each module packed in a music file. The game unpacks a file into RAM before it plays the module. agbsf2 unpacks the files in the same way. It finds them through the words in the game's code and data that point to them. Each file's module becomes a song. The files that the game's tables list come first, in the tables' order. In a game whose code and data point to no music file, agbsf2 searches the ROM for music files instead. `--info` lists the files and the module of each one. It also says which of the two ways found them.
- *Princess Natasha* plays modules 8 and 9 once, as jingles. agbsf2 finds them through the game's calls that play a file once.
- The conversion plays each module at the music volume that the game sets before it plays music. *Eragon*, *Puppy Luv: Spa and Resort* and the games with packed music files set the volume from their options. The conversion plays at the options' default. *Juka and the Monophonic Menace* fades its music in from silence at each start. The conversion fades in the same way. The marked loop then starts on the second pass.
- *Babar to the Rescue*'s mixer is mono. Every channel of the game's conversion plays in the centre.

## Known limitations

- *The Sims: Bustin' Out* plays its music at 255. There the loudest notes of a few pieces would need more than a MIDI file's full loudness. The conversion plays the music at 128, 6 dB quieter than the game. The balance between the voices stays the same.
- agbsf2 contains the volumes that the games set and *Juka and the Monophonic Menace*'s fade-in for one release of each game, by its game code. Another release, such as one from another region, plays at 128 without a fade.
- Where two channels of a module share a MIDI channel and play notes at once, each channel's pan, expression and bend act on the other channel's notes. A note that starts on a MIDI channel can also change the release of the note before it. Some pieces of *Puppy Luv: Spa and Resort* have notes that overlap that way.
- A music file can list samples that the game loads into RAM with its module. No file of the games listed above lists any. agbsf2 leaves out a module whose file lists samples and gives a warning.
- With Krawall, agbsf2 finds a jingle through a routine in the form that *Digimon Racing* has, through a table in the form that *Eragon* has, or through calls that play a music file once. A jingle that a game plays through other code converts as a loop.
- Apart from Krawall's jingles, the limitations listed for 1.7.1 still apply. See "Accuracy" and "Known issues" in the README for the details.
